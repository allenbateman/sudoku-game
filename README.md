## Installation on Mobile Devices (PWA / Offline Play)

### iPhone / iPad (iOS)
1. Open [https://allenbateman.github.io/sudoku-game/](https://allenbateman.github.io/sudoku-game/) in **Safari**.
2. Tap **Share** button -> **"Add to Home Screen"**.

### Android
1. Open [https://allenbateman.github.io/sudoku-game/](https://allenbateman.github.io/sudoku-game/) in **Chrome**.
2. Tap Menu (⋮) -> **"Install application"**.
